# Taskify App

A simple personal assistant and calculator Python application.

## Features
- **Personal Assistant**: Collects user information, generates a summary, and saves it to a file.
- **Calculator**: Supports addition, subtraction, multiplication, division, exponentiation, and root operations.

## Usage
Run the desired module with Python:
```bash
python main.py          # Personal Assistant
python calculator.py    # Calculator
python simple_assistant.py  # Simple Assistant
```
