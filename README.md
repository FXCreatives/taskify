# Taskify

A simple task management web application for creating, editing, viewing, and deleting tasks.

## Features

- Dashboard with task statistics (total, completed, pending, high priority)
- Overall progress bar
- Add, edit, and delete tasks
- Priority levels: Low, Medium, High
- Status tracking: Pending, In Progress, Completed
- Recent tasks table with quick actions
- Responsive UI with dark mode support

## Technologies Used

- **PHP** (backend with PDO for database access)
- **MySQL** (database)
- **HTML/CSS/JavaScript** (frontend)

## Setup

1. Import `taskify_db.sql` into your MySQL database.
2. Update database credentials in `includes/db.php`.
3. Serve the project with a local PHP server (e.g., `php -S localhost:8000`).
4. Visit `http://localhost:8000/taskify/` in your browser.
